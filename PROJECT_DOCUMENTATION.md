## 🎯 PROJECT OVERVIEW

**Timeless India** is an interactive web application designed to celebrate, preserve, and showcase India's rich and diverse cultural heritage through engaging digital experiences. This project uses modern web technologies to create an immersive platform where users can explore, learn, and experience the traditions, arts, monuments, and festivals that define Indian culture.

### Mission
To create a **digital archive and experience hub** that educates and excites users about India's timeless traditions using engaging, interactive, and modern web experiences.

### Target Audience
- History and culture enthusiasts
- Students learning about Indian heritage
- Travelers planning cultural tours
- Educational institutions
- Global audience interested in Indian traditions

## 🚀 INSTALLATION & SETUP GUIDE

### Prerequisites
Before you begin, ensure you have the following installed:
- **Node.js** (version 16 or higher)
- **npm** (comes with Node.js)
- **Git** (for cloning the repository)
- A code editor (VS Code, WebStorm, etc.)

### Step-by-Step Installation

#### Step 1: Clone the Repository
```bash
git clone https://github.com/AntaraA7953/Timeless-India.git
cd Timeless-India
```

#### Step 2: Install Dependencies
```bash
npm install
```

#### Step 3: Start Development Server
```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal)

#### Step 4: Build for Production
```bash
npm run build
```

This creates an optimized build in the `dist/` directory

#### Step 5: Preview Production Build
```bash
npm preview
```

### Troubleshooting Installation Issues

**Issue: npm install fails**
- Solution: Clear npm cache with `npm cache clean --force` and retry

**Issue: Port 5173 already in use**
- Solution: Run `npm run dev -- --port 3000` to use a different port

**Issue: Module not found errors**
- Solution: Delete `node_modules` folder and `package-lock.json`, then run `npm install` again

## 🎮 DETAILED GAME GUIDE

### Quiz Categories

**Heritage Monuments Quiz**
- Questions about famous Indian monuments
- Topics: Taj Mahal, Temples, Forts, Palaces
- Difficulty: Easy (10 questions), Medium (15 questions), Hard (20 questions)
- Time Limit: 2 minutes per question

**Festival Knowledge Quiz**
- Questions about Indian festivals and celebrations
- Topics: Diwali, Holi, Navratri, Pongal, and regional festivals
- Difficulty: Beginner, Intermediate, Advanced
- Time Limit: 1.5 minutes per question

**Traditional Arts Quiz**
- Questions about dance forms, music, and crafts
- Topics: Classical dances, instruments, folk arts
- Difficulty: 3 levels
- Time Limit: 2 minutes per question

**Regional Specialties Quiz**
- Questions about state-specific traditions and crafts
- Topics: Cuisine, crafts, dialects, customs
- Difficulty: Progressive
- Time Limit: 2 minutes per question
