# 🌏 Timeless India – A Cultural Odyssey

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Timeless%20India-brightgreen?style=for-the-badge&logo=vercel)](https://timeless-india.vercel.app)

**Timeless India** is a comprehensive digital archive and experience hub that celebrates India's rich, diverse cultural heritage. Built with modern web technologies, this interactive platform showcases traditions, festivals, cuisines, history, and regional cultures across all states and union territories of India.

---

## 📌 Key Features

### 1. 🗺️ **Interactive India Map**
- **Feature Name:** Interactive Map
- **Description:** Explore all 28 states and 8 union territories with an intuitive, interactive visualization
- **Functionality:**
  - Click on any state/UT to access detailed regional information
  - Visual representation of India's geographical diversity
  - Links to dedicated state pages with cultural, historical, and traditional information
  - Smooth navigation between regions

### 2. 🎨 **Cultural Mosaic**
- **Feature Name:** Cultural Mosaic Explorer
- **Description:** Deep dive into India's living traditions through curated cultural themes
- **Four Major Themes:**
  - **Weddings & Union (Theme 01)** - Ceremonies that bind families and communities
    - Punjab: Anand Karaj
    - Kerala: Thali Ceremony
    - Rajasthan: Pheras by Sacred Fire
    - Bengal: Shubho Drishti
  - **Floor & Wall Art (Theme 02)** - Temporary threshold artworks
    - Tamil Nadu: Kolam
    - West Bengal: Alpana
    - Rajasthan: Mandana
    - Uttarakhand: Aipan
  - **Birth & Naming (Theme 03)** - Rituals welcoming new members
    - Maharashtra: Barse
    - Kerala: Choroonu
    - Karnataka: Namakarana
  - **Auspicious & Protective (Theme 04)** - Symbols of protection and prosperity
    - Gujarat: Toran at the Threshold
    - Maharashtra: Gudi Padwa
    - Bihar: Kajal & Nazar
    - Tamil Nadu: Drishti Bommai

**Key Features:**
- Interactive theme cards with hover effects
- Regional mosaic display for each tradition
- Detailed story dialogs with rituals breakdown
- Step-by-step ritual journey explanations
- Visual representations and image galleries
- "Why it matters" context for each tradition

## 🧑‍💻 How to Run Locally

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager
- Supabase account (for backend features)

### Installation Steps

```bash
# 1. Clone the repository
git clone https://github.com/AntaraA7953/Timeless-India.git

# 2. Navigate to project directory
cd Timeless-India

# 3. Install dependencies
npm install

# 4. Create .env.local file with your Supabase credentials
echo "VITE_SUPABASE_URL=your_supabase_url" > .env.local
echo "VITE_SUPABASE_ANON_KEY=your_supabase_key" >> .env.local

# 5. Start development server
npm run dev

# 6. Open browser and visit
# http://localhost:5173
```

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview the production build locally
npm run preview

# Lint code for issues
npm run lint
```
